### grouptopn_001 每个二级类目下订单数量排名前3的商品名称是哪些？

- 分类：组内TopN
- 失败原因：agent_error: SQL引用校验失败：引用了不在候选 Schema 中的字段: order_count, rn
- Agent 错误：SQL引用校验失败：引用了不在候选 Schema 中的字段: order_count, rn
- 实际 SQL：

```sql
WITH product_order_count AS (
    SELECT
        dp.category_level2,
        dp.product_id,
        COUNT(DISTINCT fo.order_sn) AS order_count
    FROM fact_order fo
    INNER JOIN fact_order_detail fod
        ON fo.order_sn = fod.order_sn
    INNER JOIN dim_product dp
        ON fod.product_id = dp.product_id
    WHERE fo.order_status = '已完成'
    GROUP BY dp.category_level2, dp.product_id
),
ranked AS (
    SELECT
        category_level2,
        product_id,
        order_count,
        ROW_NUMBER() OVER (
            PARTITION BY category_level2
            ORDER BY order_count DESC, product_id ASC
        ) AS rn
    FROM product_order_count
)
SELECT
    r.category_level2,
    r.product_id,
    r.order_count
FROM ranked r
WHERE r.rn <= 3
ORDER BY r.category_level2, r.rn
```
